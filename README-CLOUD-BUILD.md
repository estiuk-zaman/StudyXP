# StudyXP — Cloud APK Build

This copy is prepared for Codemagic cloud building.

1. Create a GitHub repository named `StudyXP`.
2. Upload the contents of this folder (not the ZIP itself) to the repository.
3. In Codemagic, add the GitHub repository as a Native Android app.
4. Start the `android-debug` workflow.
5. When the build succeeds, download `app-debug.apk` from Artifacts.

No Android Studio is required for the cloud build.
